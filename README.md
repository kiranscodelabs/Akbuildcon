# AK Buildcon — real estate landing page

A responsive, single-page HTML/CSS/JavaScript recreation inspired by the supplied screenshot.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet access is only needed for the Google font. The property and leadership images are stored locally in `assets/`. No Python, Node.js, or IDE is required.

## Property images
- The home page hero and property gallery use the supplied building, rendering, interior and floor-plan images in `assets/`.
- The gallery labels the floor plan as an example; confirm it matches an available unit before sharing it as a specific unit plan.

## Included interactions
- Expandable FAQs
- Mobile navigation menu
- Contact form that opens WhatsApp with a prefilled enquiry

## Customise
- Edit the project details and starting prices in `details.html`.
- Update the hero, FAQs, and standalone contact form in their respective HTML files (`contact.html` contains the form).
- Change the main layout in `style.css` and the project detail cards in `project-details.css`.
- Set the WhatsApp recipient number in `script.js` as digits only, including the country code.

Prices are starting prices and should be confirmed with the seller. Submitting the contact form opens WhatsApp with the visitor's message prefilled; the visitor must tap Send in WhatsApp to submit it. This is a front-end website and does not connect to a property database or enquiry backend.
